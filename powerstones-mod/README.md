# Power Stones (Fabric 1.21.11)

22 power stone bertema block Minecraft. Efek hanya aktif saat batu dipegang.

## Build
Butuh JDK 21 dan Gradle 9.2+.

    gradle wrapper
    ./gradlew build

Hasil: `build/libs/powerstones-1.0.0.jar` -> taruh di folder `mods` bersama Fabric API 0.141.1+1.21.11.

Uji cepat: `./gradlew runClient`, lalu buka tab kreatif "Power Stones".
